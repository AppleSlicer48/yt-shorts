# yt-shorts

Daily animated YouTube Shorts (inventions & everyday objects), made with Claude.

- `pipeline/` — video tools (voice, animation, captions, sound). `scenes.py` is the most recent video's scenes, kept as an example.
- `topics_done.txt` — topics already used, one per line, so no video repeats.
- Finished videos are attached to this repo's GitHub Releases (one release per day); Metricool posts them from there.
